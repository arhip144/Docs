# Краш

Путь: `/guilds/:guildId/crash`

Реалтайм-игра: множитель растёт, нужно забрать ставку до краша.

## Управление

| Элемент        | Описание                                             |
| -------------- | ---------------------------------------------------- |
| Инвентарь      | Выбор предмета для ставки; избранное и поиск         |
| Тип ставки     | Валюта / предмет (печеньки — на специальном сервере) |
| Сумма          | Размер ставки                                        |
| Авто-вывод     | Целевой множитель + пресеты                          |
| Сделать ставку | На текущий или следующий раунд                       |
| Забрать Xx     | Кэшаут на текущем множителе                          |
| Чат            | Сообщения игроков                                    |
| Честность      | Seeds для проверки раунда                            |
| История        | Прошлые раунды                                       |
| Карточка       | Шеринг результата                                    |

## Ограничения

* Предмет с флагом «не разыгрываемый в краше» нельзя ставить.
* Валюта может быть запрещена настройкой «Запретить в краше».
* Discord-аналог: `/crash`.
