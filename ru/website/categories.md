# Категории магазина (сайт)

Путь: `/dashboard/:guildId/categories` → `/categories/:categoryId`

{% hint style="info" %}
Лимит: **5** без премиума, **25** с премиумом.
{% endhint %}

## Поля

| Поле | Описание |
| --- | --- |
| Название категории | Обязательное |
| Эмодзи | Эмодзи категории |
| Стандартная категория | Категория по умолчанию в магазине |
| Предметы категории | Мультивыбор предметов |

Предметы также должны быть включены в магазине у самого [предмета](items.md).

Discord: [Категории](../guide/categories.md).
