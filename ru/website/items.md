# Предметы

Путь: `/dashboard/:guildId/items` → редактирование `/dashboard/:guildId/items/:itemId`

На странице списка можно создавать, открывать и удалять предметы. Редактор сохраняет изменения кнопкой внизу страницы.

{% hint style="info" %}
Лимит слотов: **25** без премиума, **1000** с премиумом. См. [Премиум](../premium.md).
{% endhint %}

{% hint style="info" %}
В Discord то же самое делается через `/manager-items`. Краткий Discord-гайд: [Предметы](../guide/items/).
{% endhint %}

## Основные поля

Всегда видны вверху редактора.

| Поле                 | Описание                                                                  |
| -------------------- | ------------------------------------------------------------------------- |
| Эмодзи               | Эмодзи предмета. Кастомные эмодзи сервера — с премиумом                   |
| Название предмета    | 2–30 символов. Запрещены служебные имена (`currency`, `rp`, `copy` и др.) |
| Название редкости    | До 45 символов                                                            |
| Порядок сортировки   | 1–1000, влияет на порядок в списках                                       |
| Цвет предмета        | Цвет рамки/отображения                                                    |
| Описание предмета    | До 200 символов                                                           |
| Изображение предмета | URL изображения                                                           |

## Вкладки

### Магазин

| Поле                                             | Описание                                                               |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| В магазине / Не в магазине                       | Показывать ли предмет в `/shop`                                        |
| Количество                                       | Остаток на складе; можно ∞                                             |
| Цена покупки                                     | Предмет/валюта; статическая или динамическая (крипто-пара + множитель) |
| Цена продажи                                     | Аналогично цене покупки                                                |
| Скидка/штраф на покупку от репутации             | Модификатор цены покупки                                               |
| Бонус/штраф на продажу от репутации              | Модификатор цены продажи                                               |
| Дневной / недельный / месячный лимит покупки     | Сколько раз можно купить за период                                     |
| Ежедневная / еженедельная / ежемесячная доставка | Тип: увеличивает или устанавливает количество на складе + значение     |

Подробнее про крипто-цены: [Криптовалюта](../guide/items/cryptocurrency.md).

### Крафт

До 10 рецептов. В каждом рецепте:

| Поле                   | Описание                             |
| ---------------------- | ------------------------------------ |
| Ингредиенты            | До 10 пар «предмет + количество»     |
| Мин. / Макс. результат | Сколько предметов получается         |
| Рецепт известен        | Виден ли рецепт игрокам              |
| Право крафта           | Объект [прав](permissions.md)        |
| Кулдаун (сек)          | Пауза между крафтами                 |
| Мин. / Макс. за раз    | Диапазон количества за одно действие |

Игрок крафтит командой `/craft`.

### Кейс

| Поле                    | Описание                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| Режим                   | Один предмет / Несколько предметов                                                                            |
| Содержимое              | До 10 слотов. Тип: Предмет / Валюта / Опыт / Репутация / Роль / Игра Steam / Печеньки (на отдельных серверах) |
| Мин. / Макс.            | Диапазон количества                                                                                           |
| Шанс %                  | Вес выпадения                                                                                                 |
| Длительность роли (мин) | Для типа «Роль»                                                                                               |
| Валюта поиска           | Для Steam-игры (RUB, UAH, KZT, TL, USD)                                                                       |
| Ключ для открытия       | Предмет / валюта / XP / RP + количество                                                                       |

Игрок открывает кейс через `/open` или инвентарь на [профиле](profile.md).

### Использование

Предмет становится используемым (`/use`), если задано хотя бы одно действие.

#### Награды

| Действие                                   | Параметры                                            |
| ------------------------------------------ | ---------------------------------------------------- |
| Выдача уровня / репутации / опыта / валюты | Значение                                             |
| Выдача предмета                            | Предмет + количество                                 |
| Выдача роли                                | Роль; опционально «напрямую в Discord»; минуты срока |
| Выдача трофея                              | Текст трофея                                         |

#### Бустеры

| Действие                                           | Параметры           |
| -------------------------------------------------- | ------------------- |
| Бустер валюты / опыта / удачи / репутации          | Множитель %, минуты |
| Очистка бустера валюты / опыта / удачи / репутации | Переключатель       |

#### Сообщение

| Действие                | Параметры                   |
| ----------------------- | --------------------------- |
| Сообщение               | Текст (до 1000)             |
| Сообщение в ЛС          | Переключатель (нужен текст) |
| Миниатюра / Изображение | URL                         |
| Цвет рамки              | HEX                         |

#### Прогресс

| Действие                    | Параметры         |
| --------------------------- | ----------------- |
| Достижение                  | Выбор достижения  |
| Спавн червоточины           | Выбор червоточины |
| Изучение предмета / рецепта | Предмет           |
| Выдача квеста               | Квест             |
| Автодоход ролей (мин)       | Минуты            |

#### Снятие

| Действие                                      | Параметры            |
| --------------------------------------------- | -------------------- |
| Очистка роли / трофея                         | Роль или текст       |
| Удаление предмета с сервера                   | Предмет              |
| Сброс / удаление квеста                       | Квест                |
| Вычитание опыта / валюты / репутации / уровня | Значение             |
| Вычитание предмета                            | Предмет + количество |

### Способы получения

| Источник                          | Поля                                 |
| --------------------------------- | ------------------------------------ |
| Рыбалка / Майнинг                 | Шанс %, мин/макс кол-во, мин/макс XP |
| Голосовой / текстовый канал       | Шанс и количества                    |
| Лайк / приглашение / бамп сервера | Шанс и количества (бамп — премиум)   |
| Ежедневная награда (дни 1–7)      | Мин/макс за день                     |

### Свойства

| Поле                    | Описание                                                        |
| ----------------------- | --------------------------------------------------------------- |
| Известный               | Если выкл. — инфо скрыта, пока предмет не получат или не изучат |
| Видимый                 | Если выкл. — нельзя получить и взаимодействовать                |
| Передаваемый            | Разрешает `/transfer`                                           |
| Выкидываемый            | Разрешает `/drop`                                               |
| Раздаваемый             | Раздачи (нужен премиум сервера)                                 |
| Продаваемый на маркете  | Маркет (премиум)                                                |
| Продаваемый на аукционе | Аукционы                                                        |
| Разыгрываемый в краше   | Ставки в краше                                                  |
| Ставится в блекджеке    | Ставки в блекджеке                                              |

### Права (премиум)

Привязка объекта [прав](permissions.md) к действиям:

Право на покупку, продажу, открытие, использование, передачу, дроп; получение за сообщение / голос / лайк / приглашение / бамп / рыбалку / майнинг.

### Кулдауны

Для действий **Использование**, **Открытие**, **Продажа**, **Дроп**, **Передача**:

| Поле          | Описание                            |
| ------------- | ----------------------------------- |
| Кулдаун (сек) | До 2 592 000 (30 дней)              |
| Мин. за раз   | Минимальное количество за действие  |
| Макс. за раз  | Максимальное количество за действие |
