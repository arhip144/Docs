# Маркет (сайт)

Путь: `/guilds/:guildId/market`

{% hint style="warning" %}
Маркет доступен с [премиумом](../premium.md) сервера. Предмет должен быть «Продаваемый на маркете».
{% endhint %}

## Фильтры

| Фильтр | Описание |
| --- | --- |
| Предмет | По предмету лота |
| Роль | По роли |
| Продавец | По продавцу |
| Мои лоты | Только ваши |

## Действия

| Действие | Описание |
| --- | --- |
| Создать лот | Тип: Предмет / Роль; количество; цена за 1 шт. |
| Купить | Купить лот |
| Удалить | Снять свой лот |

Настройки канала и срока хранения лота — в [Настройки → Маркет](settings/shop-market.md).

Discord: команда `/market` и [гайд](../guide/market.md).
