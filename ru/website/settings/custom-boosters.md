# Кастомные роли, бустеры, CS2, отчёты топа

## Кастомные роли

Требуется [премиум](../../premium.md) для команды `/custom-role`.

| Поле                            | Описание                             |
| ------------------------------- | ------------------------------------ |
| Право на кастомные роли         | Объект [прав](../permissions.md)     |
| Канал модерации кастомных ролей | Куда приходят заявки                 |
| Позиция кастомных ролей         | Опорная Discord-роль                 |
| Отображать отдельно             | Hoist роли                           |
| Временные кастомные роли        | Разрешить timed-роли                 |
| Минимум минут                   | Минимальная длительность             |
| Лимит создания                  | Сколько ролей может создать участник |

Discord: [Кастомная роль](../../guide/custom-role.md).

## Бустеры

| Поле                        | Описание                                                |
| --------------------------- | ------------------------------------------------------- |
| Складывать бустеры          | Глобальные бустеры стакаются с предметными              |
| Глобальный бустер опыта     | Множитель % + дата окончания                            |
| Глобальный бустер валюты    | Множитель % + дата окончания                            |
| Глобальный бустер репутации | Множитель % + дата окончания                            |
| Глобальный бустер удачи     | Множитель % (может быть отрицательным) + дата окончания |

## Ранги CS2

Для каждого диапазона Premier выбирается Discord-роль (команда `/cs2rank`, премиум):

| Диапазон        |
| --------------- |
| CS2 1–4999      |
| CS2 5000–9999   |
| CS2 10000–14999 |
| CS2 15000–19999 |
| CS2 20000–24999 |
| CS2 25000–29999 |
| CS2 30000+      |

## Отчёты топа

Требуется премиум.

| Поле               | Описание         |
| ------------------ | ---------------- |
| Ежедневный отчёт   | Переключатель    |
| Еженедельный отчёт | Переключатель    |
| Ежемесячный отчёт  | Переключатель    |
| Ежегодный отчёт    | Переключатель    |
| Канал для отчётов  | Куда публиковать |
