# Основное и валюта

Путь: `/dashboard/:guildId/settings` → вкладки **Основное** / **Валюта**.

## Основное

| Поле      | Описание                                                                |
| --------- | ----------------------------------------------------------------------- |
| Язык бота | `Русский`, `English`, `Українська`, `Español`                           |
| Премиум   | Только просмотр статуса (купить — на странице [Премиум](../premium.md)) |

## Валюта

| Поле               | Описание                                      |
| ------------------ | --------------------------------------------- |
| Название           | Отображаемое имя валюты сервера               |
| Описание           | Текст о валюте                                |
| Эмодзи валюты      | Обычное или кастомное (кастом — с премиумом)  |
| Запретить передачу | Блокирует `/transfer` валюты                  |
| Запретить дроп     | Блокирует `/drop` валюты                      |
| Запретить в краше  | Нельзя ставить валюту в краш                  |
| Право передачи     | Объект [прав](../permissions.md) для передачи |
| Право дропа        | Объект прав для дропа                         |

Discord: [Настройка валюты](../../guide/currency.md).
