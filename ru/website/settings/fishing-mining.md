# Рыбалка и майнинг

Дропы предметов для рыбалки/майнинга настраиваются у каждого [предмета](../items.md) (вкладка «Способы получения») и в [Администрировании](../moderation.md) → Активности.

## Рыбалка

| Поле | Описание |
| --- | --- |
| Название рыбалки | До 20 символов (отображение в UI команды) |
| Иконка рыбалки | Эмодзи/иконка |
| Наживка | Валюта или предмет, списываемый за `/fishing` |
| Цена наживки | Стоимость одной попытки |

{% hint style="info" %}
Без премиума кулдаун `/fishing` — 30 сек; с премиумом — 0 сек.
{% endhint %}

## Майнинг

| Поле | Описание |
| --- | --- |
| Название майнинга | До 20 символов |
| Иконка майнинга | Эмодзи/иконка |
| Инструмент майнинга | Валюта или предмет за `/mining` |
| Цена майнинга | Стоимость попытки |

Кулдаун `/mining` аналогичен рыбалке (премиум снимает кулдаун).
