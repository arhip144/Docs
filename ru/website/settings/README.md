# Настройки сервера

Путь: `/dashboard/:guildId/settings`

Нужен доступ к секции **Настройки сервера**. Изменения сохраняются нижней панелью «Сохранить».

В Discord аналог — `/manager-settings`. См. [Настройка бота](../../guide/settings.md).
