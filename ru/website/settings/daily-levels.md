# Ежедневные награды и роли за уровни

## Ежедневные награды

| Поле | Описание |
| --- | --- |
| Макс. бонус за неделю | 0–5000 |
| День 1–7 | Список наград на каждый день |

Каждая награда дня:

| Поле | Описание |
| --- | --- |
| Предмет / валюта / XP / RP | Что выдаётся |
| От / До | Диапазон количества |

Дополнительно предметы могут иметь свои дропы в ежедневке — вкладка «Способы получения» у [предмета](../items.md).

## Роли за уровни

До 80 правил. В каждом:

| Поле | Описание |
| --- | --- |
| Роль | Discord-роль |
| С уровня | Нижняя граница |
| До уровня | Верхняя граница (опционально) |
