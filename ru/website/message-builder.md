# Конструктор сообщений (сайт)

Путь: `/embed` (публичный инструмент)

Позволяет собрать Discord-сообщение (классические эмбеды или Components V2), сохранить в библиотеку и отправить ботом или вебхуком.

## Режимы

| Режим | Описание |
| --- | --- |
| Эмбеды | Классические Discord embeds |
| Контейнеры | Components V2 (контейнеры, секции, галереи) |

## Классический эмбед

| Поле | Описание |
| --- | --- |
| Текст сообщения | Content над эмбедом |
| Заголовок / Ссылка заголовка | Title |
| Описание | Description |
| Цвет полоски | HEX |
| Время | Timestamp |
| Автор / ссылка / иконка | Author |
| Футер / иконка | Footer |
| Миниатюра / Изображение | URL |
| Поля | Имя, значение, «в одну линию» |
| Имя / аватар вебхука | При отправке вебхуком |

## Components V2

Контейнер (акцентный цвет, спойлер), текст, разделитель, галерея, секция, кнопки.

## Кнопки

| Поле | Описание |
| --- | --- |
| Текст | Надпись |
| Стиль | Основной / Вторичный / Успех / Опасный / Ссылка |
| Команда кнопки | Действие бота (см. ниже) |
| Флаги | Эфемерно, ответом и др. |

### Команды кнопок (примеры)

Получить подарок; Купить; Продать; Взять квест; Квест: получить награду; Отменить квест; Выдать / забрать предмет; Команды бота (help); Профиль; Инвентарь; Достижения; Ранг; свой customId.

Полный список действий кнопок также в [Кастомные кнопки](../guide/buttons.md).

## Библиотека и отправка

| Функция | Описание |
| --- | --- |
| Локально / На сервере | Где хранить шаблоны |
| Папки | Организация |
| Сохранить / загрузить | Шаблоны |
| Отправка / редактирование | Новое сообщение или правка |
| Свой вебхук / Ботом / Вебхук бота | Способ отправки (нужен вход) |
| JSON import/export | Обмен конфигурацией |
| Discord import | Импорт из сообщения Discord |
