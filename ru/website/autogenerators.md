# Автогенераторы промокодов

Путь: `/dashboard/:guildId/autogenerators` → `/autogenerators/:autogeneratorId`

{% hint style="warning" %}
Доступны только с [премиумом](../premium.md) (до 25 автогенераторов).
{% endhint %}

## Поля

| Поле                   | Описание                                              |
| ---------------------- | ----------------------------------------------------- |
| Название               | Имя автогенератора                                    |
| Включён                | Нужны канал, cron и хотя бы одна награда              |
| Право                  | Объект [прав](permissions.md)                         |
| Канал публикации       | Куда отправлять промокод                              |
| Cron-паттерн           | Когда создавать; [справка](../guide/cron-patterns.md) |
| Осталось генераций     | Безлимит или лимит                                    |
| Циклы генераций        | Сколько циклов                                        |
| Время жизни            | Минуты жизни промокода                                |
| Использований          | Лимит активаций созданного кода                       |
| Сгенерировать промокод | Ручной запуск (после сохранения)                      |
| Пул наград             | Список наград со шансами (сумма ≤ 100%)               |

Discord: [Автогенераторы](../guide/autogenerators.md).
