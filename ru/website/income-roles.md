# Доходные роли

Путь: `/dashboard/:guildId/roles` → `/roles/:roleId`

{% hint style="info" %}
Лимит: **5** без премиума, **100** с премиумом. Игрок забирает доход командой `/role-income`.
{% endhint %}

## Поля

| Поле           | Описание                                |
| -------------- | --------------------------------------- |
| Включён        | Роль активна (нужен настроенный доход)  |
| Тип роли       | Количество (фикс) / Процент (от часа)   |
| Право          | Объект [прав](permissions.md)           |
| Опыт           | Доход XP                                |
| Валюта         | Доход CUR                               |
| Репутация      | Доход RP                                |
| Кулдаун (часы) | Через сколько часов снова можно забрать |
| Уведомление    | Уведомлять о доступном доходе           |
| Предметы       | До 10 предметов в доходе                |

Discord: [Доходные роли](../guide/roles.md).
