# Выпадающие роли (Select menu роли)

## Что это?

Select-меню в сообщении бота: участник выбирает роли из списка (до 25). Можно сделать платным и с кулдауном.

## Discord

Команда [/dropdown-roles](../commands/admins.md) — по очереди укажите роли (до 25).

<figure><img src="../.gitbook/assets/Скриншот 02-05-2023 233618.png" alt=""><figcaption></figcaption></figure>

Далее настраивается:

| Параметр | Описание |
| --- | --- |
| Мульти-выбор | Несколько ролей сразу |
| Цены | Стоимость ролей |
| Отображение меню | Внешний вид |
| Кулдаун | Пауза между выборами |
| Плейсхолдер | Текст до выбора |
