# Промокоды

## Что это?

Промокоды выдают награды (предметы, валюту, XP, RP) по коду. Можно ограничить число активаций, права и даты.

{% hint style="info" %}
Лимит: **5** без премиума, **1000** с премиумом. Лишние промокоды без премиума могут быть заморожены.
{% endhint %}

## Discord

Команда: [/manager-promocodes](../commands/admins.md) (`create` / `edit` / `delete` / `view`).

Типичные настройки:

| Параметр                   | Описание                                 |
| -------------------------- | ---------------------------------------- |
| Код                        | Строка промокода                         |
| Включён                    | Нужны награды                            |
| Количество использований   | Лимит активаций                          |
| Предметы                   | Награды                                  |
| Cron сброса                | Сброс счётчика; [cron](cron-patterns.md) |
| Даты отключения / удаления | Когда выключить или удалить              |
| Право                      | Пресет [прав](permissions.md)            |

Автоматическая публикация кодов: [Автогенераторы](autogenerators.md).
