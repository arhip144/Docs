# Способы получения предмета

## Что это?

Настройки дропа предмета из рыбалки, майнинга, сообщений, войса, лайков, инвайтов, бампов и ежедневных наград.

## Discord

В `/manager-items edit` откройте **Способы получения**.

<figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>

Для каждого источника задаются шанс (%) и количество (мин/макс). Для рыбалки и майнинга — также мин/макс XP.

| Источник                    | Примечание                       |
| --------------------------- | -------------------------------- |
| Рыбалка / Майнинг           | Команды `/fishing`, `/mining`    |
| Голосовой / текстовый канал | За активность                    |
| Лайк / приглашение          | Социальные действия              |
| Бамп сервера                | Нужен премиум для наград за бамп |
| Ежедневная награда          | Дни 1–7                          |

Глобальные таблицы дропов активностей также правятся на сайте в [Администрировании](../../website/moderation.md).
