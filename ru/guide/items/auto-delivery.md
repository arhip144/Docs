# Авто-доставка предметов в магазин

## Что это?

По расписанию бот увеличивает или устанавливает количество предмета на складе магазина.

## Discord

В разделе **Магазин** предмета выберите дневную, недельную или месячную авто-доставку.

<figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

### Тип авто-доставки

<figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

| Тип                      | Смысл                          |
| ------------------------ | ------------------------------ |
| Увеличивает количество   | Прибавляет N к текущему складу |
| Устанавливает количество | Ставит склад ровно в N         |

{% hint style="info" %}
По МСК:

* дневная — 03:25
* недельная — 03:30
* месячная — 03:35
{% endhint %}
