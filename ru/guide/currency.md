# Настройка валюты сервера

## Что это?

Валюта сервера — основная единица экономики (покупки, передачи, краш, награды).

## Discord

1. Команда [/manager-settings](../commands/admins.md)
2. Пункт **Валюта сервера**

<figure><img src="../.gitbook/assets/изображение_2022-09-15_120907408.png" alt=""><figcaption><p>Предварительный просмотр и кнопки настроек</p></figcaption></figure>

Доступно:

| Настройка                       | Описание               |
| ------------------------------- | ---------------------- |
| Название / описание             | Отображение в командах |
| Эмодзи                          | Обычное или серверное  |
| Запрет передачи / дропа / краша | Ограничения            |
| Права передачи / дропа          | Через пресеты прав     |

{% hint style="info" %}
Кастомный эмодзи сервера для валюты — в [премиуме](../premium.md).
{% endhint %}

Не путайте с :cookie: печеньками (валюта премиума) — см. [Премиум](../premium.md).
