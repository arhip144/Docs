# Inventory commands

{% hint style="success" %}
These commands are available to all server members.
{% endhint %}

| Command name |                   Description                   |           Arguments            |
| :--------------: | :--------------------------------------------------: | :----------------------------: |
|      /craft      |                 **Craft an item**                |           \[item]           |
|       /drop      |        **Drop an item in a text channel**        | <item> <amount> <channel> |
|       /fav       |      **Add/remove an item from favorites**      |           \[item]           |
|    /inventory    |                **View the inventory**                |             \[user]            |
| /inventory-roles |             **View the roles inventory**             |             \[user]            |
|       /open      |                  **Open an item**                 |           \[item]           |
|      /roles      |              **Enable/disable a role**             |               None              |
|       /sell      |               **Use an item**               |     <item> \[amount]    |
|     /transfer    | **Transfer currency or an item to another user** |  <user> <item> <amount> |
|  /transfer-role  |        **Transfer a role to another user**        |   <user> <role> <amount>   |
|       /use       |               **Use an item**               |     <item> \[amount]    |
|    /promocode    |               **Redeem a promocode**              |           <promocode>           |

{% hint style="info" %}
< > - required argument \[ ] - optional argument | - OR If you can't see the commands, update your Discord client to the latest version.
{% endhint %}
