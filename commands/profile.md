# Profile commands

{% hint style="warning" %}
⭐ - [Premium command](../premium.md) ([premium.md](../premium.md "mention"))
{% endhint %}

{% hint style="success" %}
These commands are available to all server members.
{% endhint %}

| Command name |                 Description                |   Arguments  |
| :--------------: | :---------------------------------------------: | :----------: |
|   /achievements  |             **View achievements**             |    \[user]   |
|   /cookies buy   |               **Buy cookies**               | <amount> |
|   /cookies give  |           **Give cookies to the server**           | <amount> |
|     /invites     |             **View invites**            |    \[user]   |
|  /marry-divorce  |               **Get a divorce**              |    <user>    |
|      /marry      |               **Get married**               |    <user>    |
|     /profile     |              **View a profile**             |    \[user]   |
| /quests overview |               **View quests**              |    \[user]   |
|   /quests info   |               **View a quest**               |   \[quest]   |
|    ⭐/rank-set    | **Set your own properties for the rank card** |      None     |
|       /rank      |         **View the profile card**         |    \[user]   |

{% hint style="warning" %}
The following commands are available to server administrators only.
{% endhint %}

| Command name |          Description         |      Argument     |
| :--------------: | :-------------------------------: | :---------------: |
|   /trophy give   |   **Give a trophy to a user**  | \[user] \[trophy] |
|   /trophy take   | **Take a trophy from a user** | \[user] \[trophy] |

{% hint style="info" %}
< > - required argument \[ ] - optional argument | - OR If you can't see the commands, update your Discord client to the latest version.
{% endhint %}
