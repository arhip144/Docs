# Context commands

{% hint style="info" %}
RMB - right mouse button\
On mobile devices - long-press
{% endhint %}

{% hint style="info" %}
:hammer: - requires the **Administrator** permission
{% endhint %}

|      Command name     |            Description           |                      Usage                     |
| :-----------------------: | :-----------------------------------: | :-------------------------------------------------: |
| :hammer:Delete components |    Remove components from a message    | Message -> RMB -> Apps -> Delete components |
|    :hammer:Edit message   |     Edit the content of a message     |   Message -> RMB -> Apps -> Edit message    |
|       Embed to JSON       |  Convert an embed object to JSON format |   Message -> RMB -> Apps -> Embed to JSON   |
|         Get avatar        |      Get a user's avatar     |   User -> RMB -> Apps -> Get avatar   |
|         Get emojis        | Get the custom emojis in a message |     Message -> RMB -> Apps -> Get emojis    |
|       Like the user       |         Like a user         |  User -> RMB -> Apps -> Like the user |
|          Profile          |    View a user's profile    |     User -> RMB -> Apps -> Profile    |
|       :hammer:Repeat      |   Repeat a message as the bot   |       Message -> RMB -> Apps -> Repeat      |
