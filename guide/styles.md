# Creating wormhole styles

Styles define the look of the wormhole embed when it appears and when it is collected.

{% hint style="info" %}
Limit: **5** without premium, **25** with premium.
{% endhint %}

{% content-ref url="wormholes.md" %}
[wormholes.md](wormholes.md)
{% endcontent-ref %}

Open the style editing panel with the command [/manager-styles](../commands/admins.md)

<figure><img src="../.gitbook/assets/изображение_2022-10-06_115129304.png" alt=""><figcaption></figcaption></figure>

Click the create button and enter a style name, after which the style editing panel appears

<figure><img src="../.gitbook/assets/изображение_2022-10-06_115343476.png" alt=""><figcaption></figcaption></figure>

Click edit and select the style you just created.

<figure><img src="../.gitbook/assets/изображение_2022-10-06_115517752.png" alt=""><figcaption></figcaption></figure>

The panel is very convenient because it immediately shows how the wormhole itself will look and how it will look after the button is clicked

### Edit the appearance style...

* Change the description, thumbnail, image, color...

<figure><img src="../.gitbook/assets/изображение_2022-10-06_115905859.png" alt=""><figcaption></figcaption></figure>

1. <mark style="color:purple;">Description</mark> - where {item\_emoji} is the item's emoji and {item\_name} is the item's name
2. <mark style="color:purple;">Thumbnail</mark>
3. <mark style="color:purple;">Image</mark>
4. <mark style="color:purple;">Border color</mark>

{% hint style="warning" %}
Leave {item\_emoji} and {item\_name} unchanged `if you are going to use the style for several wormholes with different items.`
{% endhint %}

{% content-ref url="../variables/styles.md" %}
[styles.md](../variables/styles.md)
{% endcontent-ref %}

* Change the header and footer

<figure><img src="../.gitbook/assets/изображение_2022-10-06_120343560.png" alt=""><figcaption></figcaption></figure>

* Change the button emoji and button text

<figure><img src="../.gitbook/assets/изображение_2022-10-06_120447122.png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
The emoji field must not contain text unless it is the ID of a server emoji.
{% endhint %}

### Edit the collection style...

* Change the description, thumbnail, image, color...
* Change the header and footer
