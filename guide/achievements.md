# Creating achievements

## What is this?

Achievements are awarded for progress (messages, voice, items, crash, etc.) and can give rewards.

{% hint style="info" %}
Limit: **5** without premium, **1000** with premium.
{% endhint %}

## Discord

Create one with: [/manager-achievements create \<name\>](../commands/admins.md)

<figure><img src="../.gitbook/assets/изображение_2022-10-20_162813699.png" alt=""><figcaption></figcaption></figure>

In the editor you set the name, emoji, task type, amount, related items/roles, and rewards (up to 5).

### Commonly confused types

* **Custom goal** — not awarded automatically, only by an admin
* **XX hours in voice** — requires more than 1 participant with a microphone; bots don't count
* **Receive XX likes** — the [/like](../commands/general.md) command
* **Bump the server** — depends on the bump bot (`/bump`, `/up`, `/like`)
* **Find all items** — the "Extraordinary" rarity is not counted

How players view them: achievement commands in the [profile](../commands/profile.md).
