# Setting up the bot

## What is this?

The server's central settings: currency, channels, activities, fishing, shop, logs, and much more.

## Discord

Open the panel with the [/manager-settings](../commands/admins.md) command.

<figure><img src="../.gitbook/assets/изображение_2022-10-19_220318653.png" alt=""><figcaption><p>Viewing general information</p></figcaption></figure>

The menu has these groups:

| Group | What you can configure |
| --- | --- |
| Fishing / Mining | Names, icons, attempt price |
| Autovoice channels | Join-to-create; see [AVC](avc.md) |
| Shop | Name, preview, messages |
| Channels | Notifications, market, giveaways, muted |
| Roles | Pings, muted, roles for newcomers |
| [Server currency](currency.md) | Name, emoji, transfer restrictions |
| Daily rewards | Rewards for days 1–7 |
| Level roles | Role for a level range |
| Top leader reports | Automatic reports (premium) |
| [Earning currency/experience](receiving.md) | Rewards for activity |
| CS2 roles | Premier rank → role mapping |
| Logs | Webhook and events (some are premium) |
| Starter kit | What newcomers receive |
| [API](../api/docs.md) | API documentation |
| [Custom roles](custom-role.md) | Permissions and limits |
| Market / auctions | Channel and listing duration |
| Season / boosters | Season levels, global multipliers |

{% hint style="warning" %}
Extended logs, top reports, and custom emojis require [premium](../premium.md).
{% endhint %}
