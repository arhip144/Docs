# Creating a case

A case gives a random reward from a pool (item, currency, XP, RP, role, Steam game). Mode: one item or several. The `/open` cooldown is removed by premium.

To create a case in Discord, go to the "Case" section

<figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>

Choose what you want to add to the case, and a modal window will open for selecting the chance and the item amount.

<figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
The maximum number of items in a case is 10
{% endhint %}

{% hint style="info" %}
The sum of all item chances in a case must not exceed 100%
{% endhint %}

{% hint style="info" %}
The ![](<../../.gitbook/assets/image (20).png>) button removes the corresponding entry from the case
{% endhint %}

***

## Requiring a key for a case

If you want your case to be opened with an item, experience, currency, or reputation, go to the "Case (key)" section

{% hint style="info" %}
With the ![](<../../.gitbook/assets/image (21).png>) buttons you can add the corresponding key
{% endhint %}

{% hint style="info" %}
The ![](<../../.gitbook/assets/image (22).png>) button removes the key requirement
{% endhint %}

***

<figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>
