# Using an item

## What is this?

If an item has at least one action in the "Use" section, players can consume it with the `/use` command.

## Discord

In `/manager-items edit`, open the **Use** section and set the effects.

<figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

Effect groups:

| Group | Examples |
| --- | --- |
| Rewards | Level, XP, RP, currency, item, role, trophy |
| Boosters | CUR/XP/Luck/RP multipliers or clearing them |
| Message | Text, DM, image, border color |
| Progress | Achievement, wormhole, learning a recipe, quest |
| Removal | Take a role/item/XP/currency, reset a quest |

Player command: [/use \<name\> \<amount\>](../../commands/inventory.md)

<figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>

You can restrict the permission to use the item (premium) and set a usage cooldown.
