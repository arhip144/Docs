# Items

Items are the foundation of the economy: the shop, crafting, cases, drops, and `/use`.

{% hint style="info" %}
Slot limit: **25** without premium, **1000** with premium. See [Premium](../../premium.md).
{% endhint %}

The editor also lets you configure properties (known, visible, transferable…), permissions, and cooldowns. The full catalog of fields is on the [website](../../website/items.md).

## Creating an item

To create an item, run the command[ /manager-items create <item name>](../../commands/admins.md)

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
The maximum length of an item name is 30 characters
{% endhint %}

## Editing an item

To edit an item, run the command [/manager-items edit <item name>](../../commands/admins.md)

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

## Deleting an item

To delete an item, run the command [/manager-items delete <item name>](../../commands/admins.md)

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

## Copying an item

To copy an item, run the command [/manager-items copy <item name> <new item name>](../../commands/admins.md)

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
