# Adding an item to the shop

## What is this?

The server shop (`/shop`, `/buy`) sells items with a price, limits, and stock.

## Discord

In `/manager-items edit`, open the **Shop** section.

<figure><img src="../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
For an item to appear in the shop:

1. Stock amount > 0 (or ∞)
2. A purchase price is set
3. The item is marked as "in shop"
4. The **Visible** property is enabled
5. The item is saved (created)
{% endhint %}

You can also configure:

- the sell price;
- a static or [dynamic (crypto)](cryptocurrency.md) price;
- a discount/penalty based on reputation;
- a daily / weekly / monthly purchase limit;
- [auto-delivery](auto-delivery.md) to stock;
- the permission to buy/sell (premium).

Shop categories: [Categories](../categories.md).
