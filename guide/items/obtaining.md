# Ways to obtain an item

## What is this?

Settings for an item dropping from fishing, mining, messages, voice, likes, invites, bumps, and daily rewards.

## Discord

In `/manager-items edit`, open **Ways to obtain**.

<figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>

For each source you set a chance (%) and an amount (min/max). For fishing and mining, min/max XP is also set.

| Source | Note |
| --- | --- |
| Fishing / Mining | The `/fishing` and `/mining` commands |
| Voice / text channel | For activity |
| Like / invite | Social actions |
| Server bump | Premium is required for bump rewards |
| Daily reward | Days 1–7 |

Global activity drop tables can also be edited on the website under [Administration](../../website/moderation.md).
