# Создание работы

## Что это?

Работы — действия для команды `/work`: игрок выбирает работу и действие, получает успех или провал с наградами и кулдаунами.

{% hint style="warning" %}
Команда `/work` доступна с [премиумом](../premium.md).
{% endhint %}

## Discord

Команда [/manager-jobs](../commands/admins.md):

| Аргумент    | Описание              |
| ----------- | --------------------- |
| создать     | Создать новую работу  |
| изменить    | Изменить существующую |
| скопировать | Скопировать           |
| удалить     | Удалить               |
| просмотр    | Список всех работ     |

### Что настраивается

* Название, эмодзи, описание, включена/скрыта
* Два действия (название + право)
* Для успеха и провала: шанс, сообщения, изображения, кулдауны, награды (валюта/XP/RP/предмет)

Переменные в сообщениях: [Переменные: работа](../variables/jobs.md).

Игрок использует [/work](../commands/general.md).
