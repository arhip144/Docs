# Автогенераторы промокодов

## Что это?

По [cron-расписанию](cron-patterns.md) бот создаёт промокод из пула наград и публикует его в канал.

{% hint style="warning" %}
Доступно только с [премиумом](../premium.md) (до 25 автогенераторов). Команда: [/promocode-autogenerators](../commands/admins.md).
{% endhint %}

## Что настраивается

| Параметр                    | Описание                          |
| --------------------------- | --------------------------------- |
| Название / включён          | Базовые флаги                     |
| Канал публикации            | Куда отправлять код               |
| Cron-паттерн                | Когда генерировать                |
| Осталось генераций          | Лимит или безлимит                |
| Время жизни / использований | Параметры создаваемого промокода  |
| Пул наград                  | Награды со шансами (сумма ≤ 100%) |
| Право                       | Кто может активировать            |

Связано с [промокодами](promocodes.md).
