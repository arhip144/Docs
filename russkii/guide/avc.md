# Автоголосовые каналы

## Что это?

Join-to-create: участник заходит в канал-кнопку — бот создаёт временный голосовой канал и удаляет его, когда все вышли.

## Discord

В [/manager-settings](../commands/admins.md) выберите **Автоголосовые каналы**.

<figure><img src="../.gitbook/assets/изображение_2022-10-20_004728806.png" alt=""><figcaption></figcaption></figure>

| Параметр       | Описание                        |
| -------------- | ------------------------------- |
| Канал создания | Голосовой канал-кнопка          |
| Категория      | Куда создавать временные каналы |
| Название       | Шаблон имени канала             |

{% hint style="warning" %}
Создайте отдельную категорию для автовойсов: бот удаляет пустые каналы (кроме канала-кнопки).
{% endhint %}

{% hint style="success" %}
Переменные названия: [Переменные AVC](../variables/avc.md)

> **{creator}** — имя создателя\
> **#** — номер канала\
> **{emoji}** — случайный эмодзи
{% endhint %}

Бот должен иметь права управлять каналами и перемещать участников (см. [введение](../)).
