# Создание доходных ролей

## Что это?

Доходная роль периодически даёт владельцу опыт, валюту, репутацию и/или предметы. Игрок забирает доход командой `/role-income`.

{% hint style="info" %}
Лимит слотов: **5** без премиума, **100** с премиумом. См. [Премиум](../premium.md).
{% endhint %}

## Discord

Создание: [/manager-roles](../commands/admins.md) `create` <роль>

Настройки:

1. Тип: фиксированное количество или процент
2. Опыт / валюта / репутация
3. Предметы (до 10)
4. Кулдаун в часах
5. Уведомление о готовности
6. Право на получение дохода

Команда игрока: [/role-income](../commands/inventory.md)
