# Инвентарь ролей

## Что это?

Роли можно хранить в инвентаре и надевать/снимать, не теряя их навсегда. Удобно для кастомных и временных ролей.

## Просмотр

Команда [/inventory-roles](../commands/inventory.md)

## Способы получить роль в инвентарь

1. Снять роль из профиля
2. Открыть из [предмета](items/)
3. Купить на [маркете](market.md) (`/market`, премиум)
4. Получить в раздаче (`/manager-giveaways`, премиум)
5. Награда за [квест](quests.md)
6. Передача (`/transfer-role`)
7. [Кастомная роль](custom-role.md)
8. Админ-команда `/give role`
9. Награда за [достижение](achievements.md)

## Условия снятия роли из профиля

Команда [/role-properties](../commands/admins.md) → свойство **Можно снять** = Да.

<figure><img src="../.gitbook/assets/Скриншот 21-01-2024 163445.png" alt=""><figcaption></figcaption></figure>

Другие флаги: нельзя передать / продать / раздать / на аукцион. На сайте — вкладка [Администрирование → Свойства роли](../website/moderation.md).

{% hint style="warning" %}
Снятие и надевание требуют права «Управление ролями»; роль должна быть ниже роли бота.
{% endhint %}
