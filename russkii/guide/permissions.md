# Права

## Что это?

Пресет прав — набор условий (роли, предметы, уровень, время UTC и т.д.). Его подключают к покупке предмета, квесту, подарку, промокоду и другим действиям.

{% hint style="warning" %}
Создание пресетов требует [премиум](../premium.md). Команда: [/manager-permissions](../commands/admins.md).
{% endhint %}

## Discord

1. `/manager-permissions create` <название>
2. Добавьте требования (до 10)
3. Включите пресет
4. Укажите его ID в нужном менеджере (предмет, квест, подарок…)

Примеры условий: роли (все / любая / кроме), предмет в инвентаре, достижение, квест, каналы, дни недели, уровень, статистика за период, бустеры %.
