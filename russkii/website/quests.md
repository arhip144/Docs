# Квесты

Путь: `/dashboard/:guildId/quests` → `/quests/:questId`

{% hint style="info" %}
Лимит: **5** без премиума, **1000** с премиумом. До 5 задач и 5 наград на квест.
{% endhint %}

## Основные поля

| Поле               | Описание                                           |
| ------------------ | -------------------------------------------------- |
| Название           | 2–30 символов                                      |
| Эмодзи             | Эмодзи квеста                                      |
| Включён            | Квест доступен                                     |
| Активный           | Участвует в ротации/выдаче                         |
| Описание           | До 1024 символов                                   |
| Цвет               | Цвет эмбеда                                        |
| Изображение        | URL                                                |
| Тип                | Ежедневный / Еженедельный / Сообщество / Повторный |
| Условие выполнения | Все задачи / Любая задача                          |

## Вкладка «Задачи»

До 5 целей. У каждой:

| Поле                | Описание                                                                     |
| ------------------- | ---------------------------------------------------------------------------- |
| Тип задачи          | См. список ниже                                                              |
| Количество          | Порог                                                                        |
| Объект              | Канал / пользователь / предмет / квест / червоточина / промокод (если нужно) |
| Замена описания     | Свой текст задачи                                                            |
| Прогресс-бар        | Показывать прогресс                                                          |
| Опциональная задача | Не обязательна для завершения; можно задать отдельные награды                |

### Типы задач

Написать сообщений; провести минут в войсе; поставить лайков; пригласить; бамп; накопить/потратить валюту; рыбалка/майнинг; ежедневка; червоточина; выполнить квесты; создать раздачу; маркет (продажа); открыть/получить/скрафтить/использовать/купить/продать предметы; заспавнить червоточину; уровни/опыт; дроп/передача предметов; сезонный уровень/опыт; промокод; передать предметы NPC.

## Вкладка «Награды»

До 5: Опыт / Репутация / Валюта / Предмет / Роль / Достижение. Для роли — длительность в минутах.

## Вкладка «Следующие квесты»

До 3 квестов, выдаваемых после завершения.

## Вкладка «Действия»

Массовая/персональная выдача и снятие квеста, правка прогресса.

## Вкладка «Права»

| Поле                   | Описание                      |
| ---------------------- | ----------------------------- |
| Право взять квест      | Объект [прав](permissions.md) |
| Право получить награду | Объект прав                   |
