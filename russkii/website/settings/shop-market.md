# Магазин, маркет, аукционы

## Магазин

Серверный магазин бота (`/shop`, `/buy`). Ассортимент задаётся у [предметов](../items.md) и [категорий](../categories.md).

| Поле               | Описание                                                                        |
| ------------------ | ------------------------------------------------------------------------------- |
| Название магазина  | До 25 символов                                                                  |
| Превью магазина    | URL миниатюры                                                                   |
| Сообщения магазина | До 10 строк (до 50 символов). Плейсхолдеры: `{member}`, `{currency}`, `{guild}` |

## Маркет

Игрок-игроку лоты на сайте и в Discord. Нужен [премиум](../../premium.md).

| Поле                     | Описание              |
| ------------------------ | --------------------- |
| Канал маркета            | Куда публикуются лоты |
| Срок хранения лота (дни) | 0–365                 |

См. [Маркет на сайте](../market.md).
