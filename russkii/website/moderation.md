# Администрирование

Путь: `/dashboard/:guildId/moderation`

Нужен доступ к секции **Администрирование**.

## Вкладка «Участник»

Выберите пользователя, затем действие.

### Выдать или забрать

Добавляет или уменьшает: уровень, сезонный уровень, опыт, валюту, лайки, репутацию, роль (в инвентаре ролей).

### Поставить точное значение

Записывает точное значение (не прибавляет): уровень, опыт, валюта, лайки, репутация; бусты удачи / опыта / валюты / репутации.

### Выдать или забрать предмет

Кладёт предмет в инвентарь или снимает.

### Достижения / Квесты

Выдать или снять достижение / квест.

### Трофеи

Добавить строку трофея (макс. 10 на пользователя).

### Лимиты покупок

Сброс дневного / недельного / месячного лимита. Без предмета — все лимиты периода.

### Награды за активности

Переключатели для выбранного пользователя (выкл. = запрет награды):

Опыт / валюта / репутация / предметы × сообщение / голос / приглашение / бамп / лайк.

## Вкладка «Сервер»

### Очистка

Стирает выбранные данные. Пустой список пользователей = все на сервере.

Варианты: валюта; уровень и опыт; сезонный уровень; репутация; инвентарь; инвентарь ролей; достижения; квесты; трофеи; бусты; остатки магазина; статистика (alltime/day/week/month/year); кулдауны работ; ежедневные награды; приглашения; роли профиля.

{% hint style="danger" %}
Очистка необратима. См. также [Вайп](../wipe.md).
{% endhint %}

### Роль всем участникам

Выдать или снять Discord-роль (до 500 участников за запрос).

### Заспавнить червоточину

Мгновенный спавн включённой червоточины.

### Свойства роли

Флаги инвентаря ролей: Можно снять; Нельзя передать / продать / раздать / на аукцион.

### Резервные копии

Сохранить или восстановить: предметы, достижения, квесты, категории, подарки, доходные роли, червоточины, стили, профили, работы, права, промокоды, автогенераторы.

## Вкладка «Активности»

Таблица дропов для рыбалки / майнинга / голоса / сообщений:

| Поле            | Описание               |
| --------------- | ---------------------- |
| Предмет         | Что выпадает           |
| Шанс %          | Сумма шансов ≤ 100     |
| Мин. / Макс.    | Количество             |
| Мин. / Макс. XP | Для рыбалки и майнинга |

## Вкладка «Кулдауны»

| --------------- | --------------------------------- |
| Кулдаун команды | Команда + секунды                 |
| Иммунные роли   | Роли без ожидания кулдауна команд |
