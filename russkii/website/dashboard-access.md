# Панель управления и доступ

## Хаб панели

Путь: `/dashboard/:guildId`

На хабе отображаются карточки секций. Видны только те секции, к которым у вас есть доступ. Также на хабе есть:

| Карточка              | Кто видит               | Описание                     |
| --------------------- | ----------------------- | ---------------------------- |
| Секции из списка ниже | По ролям / админы       | Предметы, квесты, настройки… |
| Премиум               | Все с доступом к панели | Статус и покупка премиума    |
| Экспорт и импорт      | Только админы панели    | Перенос конфигурации         |

## Кто считается администратором панели

Полный доступ ко всем секциям, настройке доступа и экспорту/импорту имеют:

* владелец бота;
* владелец сервера;
* участники с правом Discord **Administrator**;
* участники с флагом управления доступом к панели (`canManageDashboardAccess`).

## Секции с ролевым доступом

Администратор может назначить Discord-роли на каждую секцию (модалка **Доступ к панели управления**). Для каждой секции — мультивыбор «Роли с доступом к панели» (до 25 ролей).

| Ключ             | Название в UI         |
| ---------------- | --------------------- |
| `items`          | Предметы              |
| `achievements`   | Достижения            |
| `categories`     | Категории магазина    |
| `gifts`          | Подарки               |
| `permissions`    | Права                 |
| `promocodes`     | Промокоды             |
| `quests`         | Квесты                |
| `jobs`           | Работа                |
| `incomeRoles`    | Доходные роли         |
| `styles`         | Стили червоточин      |
| `wormholes`      | Червоточины           |
| `autogenerators` | Автоген. промокодов   |
| `bonusChannels`  | Бонусные каналы       |
| `messageBuilder` | Конструктор сообщений |
| `settings`       | Настройки сервера     |
| `moderation`     | Администрирование     |

{% hint style="info" %}
Старый формат (один плоский список ролей) трактуется как одинаковый доступ ко всем секциям.
{% endhint %}

## Если секция недоступна

* Проверьте роль в Discord и настройки доступа на хабе.
* Попросите владельца сервера или администратора выдать роль на нужную секцию.
* Для подарков, прав и автогенераторов также нужен [премиум](../premium.md) на создание объектов.
