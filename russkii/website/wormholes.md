# Червоточины

Путь: `/dashboard/:guildId/wormholes` → `/wormholes/:wormholeId`

{% hint style="info" %}
Лимит: **5** без премиума, **100** с премиумом.
{% endhint %}

## Поля

| Поле                | Описание                                             |
| ------------------- | ---------------------------------------------------- |
| Название            | Имя червоточины                                      |
| Включён             | Нужны предмет, шанс, количество, cron и канал        |
| Право               | Кто может забрать                                    |
| Предмет             | Награда: предмет / валюта / XP / RP                  |
| Шанс                | Шанс спавна до 100%                                  |
| Количество от / до  | Диапазон награды                                     |
| Cron-паттерн        | Когда спавнить; [справка](../guide/cron-patterns.md) |
| Осталось спавнов    | Безлимит или лимит                                   |
| Канал вебхука       | Канал публикации                                     |
| Стиль               | [Стиль червоточины](styles.md)                       |
| Время жизни         | Секунды до исчезновения                              |
| Удалять после сбора | Убрать сообщение после взятия                        |
| Показывать дату     | Отображать дату спавна                               |

Discord: [Червоточины](../guide/wormholes.md).
