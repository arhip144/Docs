# Топ

Путь: `/guilds/:guildId/top`

## Режимы

| Режим      | Описание                               |
| ---------- | -------------------------------------- |
| Статистика | Метрики активности и экономики         |
| Предмет    | Топ по количеству конкретного предмета |

## Периоды

За всё время / За день / За неделю / За месяц / За год.

## Метрики (режим «Статистика»)

| Метрика              | Примечание            |
| -------------------- | --------------------- |
| Опыт                 | —                     |
| Сезонный опыт        | Только «За всё время» |
| Голосовая активность | Часы                  |
| Сообщения            | —                     |
| Лайки                | —                     |
| Валюта               | —                     |
| Приглашения          | —                     |
| Бампы                | —                     |
| Червоточины          | Взятые                |
| Репутация            | —                     |
| Раздачи              | Созданные             |
| Квесты               | Выполненные           |

Кнопка **Найти себя** прокручивает к вашей позиции.

Автоматические отчёты в канал — [Настройки → Отчёты топа](settings/custom-boosters.md) (премиум).
