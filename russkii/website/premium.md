# Премиум на сайте

Путь: `/dashboard/:guildId/premium`

Полный список возможностей и лимитов слотов: [Премиум](../premium.md).

## Статус

Отображается срок: **БЕССРОЧНО**, дата окончания или «премиум отсутствует».

## Тарифы

| План                    | Описание                    |
| ----------------------- | --------------------------- |
| Пробный премиум (7 дн.) | Пробный период              |
| Месяц премиума          | 🍪100 / 200₽                |
| Пожизненный премиум     | 🍪500 / 1000₽ (рекомендуем) |

## Печеньки

| Блок                   | Описание                                                                  |

| Баланс печенек сервера | Сколько 🍪 на сервере                                                     |
| Передать               | Перевести ваши печеньки на сервер                                         |
