# Права (сайт)

Путь: `/dashboard/:guildId/permissions` → `/permissions/:permissionId`

{% hint style="warning" %}
Создание прав требует [премиум](../premium.md). Пресеты используются в предметах, квестах, подарках, промокодах и др.
{% endhint %}

## Основные поля

| Поле | Описание |
| --- | --- |
| Название | 2–30 символов |
| Включён | Пресет активен |
| Тест | Проверка условий на себе |

## Требования

До 10 условий. Типы:

| Тип | Описание |
| --- | --- |
| Роли | hasAll / hasAny / except (до 25 ролей) |
| Предмет в инвентаре | Нужен предмет |
| Выполнено / не выполнено достижение | Достижение |
| Каналы | До 10 каналов |
| Выполнен квест | Квест |
| Время (UTC) | Диапазон времени |
| Дни недели | Воскресенье–суббота |
| Находиться на сервере (минуты) | MemberSince |
| Уровень / сезонный уровень / опыт | Числовые пороги |
| Сессионные метрики войса | XP/RP/часы/валюта сессии |
| Сообщения, часы, RP, лайки, валюта… | Статистика |
| Бустер XP/RP/CUR/Luck (%) | Наличие бустера |
| Статистика за день/неделю/месяц/год | Опыт, сообщения, часы, RP, лайки, валюта, инвайты, бампы, раздачи, червоточины, квесты, маркет |
