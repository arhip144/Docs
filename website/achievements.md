# Достижения (сайт)

Путь: `/dashboard/:guildId/achievements` → `/achievements/:achievementId`

{% hint style="info" %}
Лимит: **5** без премиума, **1000** с премиумом.
{% endhint %}

## Основные поля

| Поле | Описание |
| --- | --- |
| Название | 2–30 символов |
| Эмодзи | Эмодзи достижения |
| Включено | Активно ли достижение |

## Задача

| Поле | Описание |
| --- | --- |
| Выберите задачу | Тип условия (список ниже) или «Своя задача» |
| Количество | Порог XX (если тип числовой) |
| Предметы задачи | До 5 предметов (для типов «найти/скрафтить/выловить/выкопать предмет») |
| Роли задачи | До 10 ролей (тип «Получить роль») |

### Типы задач

- Написать XX сообщений в чате
- Провести XX часов в голосовом чате
- Получить XX лайков
- Пригласить XX чел. на сервер
- Бампнуть сервер XX раз(а)
- Накопить / потратить валюту (XX)
- Порыбачить / выкопать XX раз(а)
- Найти / скрафтить предмет
- Дотронуться до червоточины XX раз(а)
- Получать ежедневную награду XX дн. подряд
- Достичь репутации XX
- Выполнить квесты XX раз(а)
- Найти все предметы
- Создать раздачу / выиграть в раздаче XX раз(а)
- Продать XX предметов на маркете
- Провести XX ч. подряд в голосовом канале
- Открыть / получить / скрафтить / использовать / купить / продать XX предметов
- Заспавнить червоточину XX раз(а)
- Получить роль
- Достигнуть XX уровня / сезонного уровня
- Проголосовать за бота / задонатить (сервер поддержки)
- Выполнить все достижения
- Забустить сервер XX раз(а)
- Поработать XX раз(а)
- Выловить / выкопать предмет
- Использовать промокод XX раз(а)
- Находиться на сервере XX минут
- Выиграть ставку XX или больше в «Краш»

## Награды

До 5 наград. Типы: Опыт / Репутация / Валюта / Предмет / Роль + количество.

Discord: [Создание достижений](../guide/achievements.md).
