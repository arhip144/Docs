# Shop categories (website)

Path: `/dashboard/:guildId/categories` → `/categories/:categoryId`

{% hint style="info" %}
Limit: **5** without premium, **25** with premium.
{% endhint %}

## Fields

| Field | Description |
| --- | --- |
| Category name | Required |
| Emoji | Category emoji |
| Default category | Default category in the shop |
| Category items | Multi-select items |

Items must also be enabled in the shop on the [item](items.md) itself.

Discord: [Creating a category in the shop](../guide/categories.md).
