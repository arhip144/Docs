# Сайт wetbot.space

[https://wetbot.space](https://wetbot.space/) — веб-интерфейс бота WETBOT. На сайте можно управлять экономикой сервера, настраивать предметы и квесты, модерировать участников, открывать профиль, играть в краш и собирать сообщения в конструкторе.

## Быстрый старт

1. Откройте [wetbot.space](https://wetbot.space/) и нажмите **Войти**.
2. Авторизуйтесь через Discord (права `identify` и `guilds`).
3. Перейдите в **Мои серверы** и выберите сервер, где есть бот.
4. Откройте **Панель управления** — если у вас есть права администратора или роль с доступом к секции.

{% hint style="info" %}
Пригласить бота: [https://wetbot.space/invite](https://wetbot.space/invite)
{% endhint %}
