# Промокоды (сайт)

Путь: `/dashboard/:guildId/promocodes` → `/promocodes/:code`

{% hint style="info" %}
Лимит: **5** без премиума, **1000** с премиумом. Без премиума лишние промокоды могут быть заморожены.
{% endhint %}

## Поля

| Поле | Описание |
| --- | --- |
| Промокод | Код (строка) |
| Включён | Активен (нужны предметы в награде) |
| Количество использований | Лимит активаций |
| Предметы в промокоде | Награды |
| Cron-паттерн сброса использований | [Cron](../guide/cron-patterns.md) |
| Дата отключения | Когда выключить |
| Дата удаления | Когда удалить |
| Право для промокода | Объект [прав](permissions.md) |
| Использования | Список пользователей, активировавших код |

См. также [Автогенераторы](autogenerators.md).

Discord: [Промокоды](../guide/promocodes.md).
