# Бонусные каналы (сайт)

Путь: `/dashboard/:guildId/channels` → `/channels/:channelId`

{% hint style="info" %}
Лимит: **5** без премиума, **100** с премиумом.
{% endhint %}

Канал выбирается при создании записи (привязка к Discord-каналу).

## Поля

| Поле | Описание |
| --- | --- |
| Включён | Множитель активен |
| Множитель опыта | Коэффициент XP |
| Множитель валюты | Коэффициент CUR |
| Множитель репутации | Коэффициент RP |
| Множитель удачи | Коэффициент luck |
| Множители от числа участников | Доп. множители по метрикам с мин/макс участников |

Discord: [Бонусные каналы](../guide/bonuses.md).
