# Bonus channels (website)

Path: `/dashboard/:guildId/channels` → `/channels/:channelId`

{% hint style="info" %}
Limit: **5** without premium, **100** with premium.
{% endhint %}

The channel is chosen when creating the entry (linked to a Discord channel).

## Fields

| Field | Description |
| --- | --- |
| Enabled | Multiplier is active |
| XP multiplier | XP coefficient |
| Currency multiplier | CUR coefficient |
| Reputation multiplier | RP coefficient |
| Luck multiplier | Luck coefficient |
| Member-count multipliers | Extra multipliers by metrics with min/max members |

Discord: [Creation of bonus channels](../guide/bonuses.md).
