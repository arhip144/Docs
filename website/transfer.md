# Экспорт и импорт (сайт)

Путь: `/dashboard/:guildId/transfer`

{% hint style="warning" %}
Доступно только **администраторам панели** (владелец сервера, Administrator, управление доступом).
{% endhint %}

Позволяет сохранить настройки и контент сервера в JSON и загрузить обратно.

## Типы контента

Совпадают с секциями дашборда (кроме администрирования): предметы, достижения, категории, подарки, права, промокоды, квесты, работа, доходные роли, стили, червоточины, автогенераторы, бонусные каналы, конструктор сообщений, настройки сервера.

Для импорта **прав**, **подарков** и **автогенераторов** нужен [премиум](../premium.md).

## Экспорт

1. Выберите типы (или «Выбрать все»).
2. Нажмите **Скачать JSON**.

## Импорт

1. Выберите файл экспорта.
2. Отметьте типы контента.
3. Режим:
   - **Объединить** — добавить/обновить без полной очистки;
   - **Заменить** — удалить выбранные типы на сервере, затем импортировать.
4. При необходимости сопоставьте **доходные роли** и **бонусные каналы** с ролями/каналами текущего сервера (строки без выбора пропускаются).
5. Подтвердите импорт.

Отчёт показывает: создано / обновлено / заморожено / удалено, предупреждения и ошибки.
