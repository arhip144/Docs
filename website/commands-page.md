# Каталог команд на сайте

Путь: `/commands`

Публичная страница со списком slash-команд бота.

## Возможности

| Элемент | Описание |
| --- | --- |
| Поиск | Фильтр по названию и описанию |
| Категории | Общие, магазин, инвентарь, профиль, админ, менеджеры, игры |
| Бейджи | Премиум / админ |
| Копирование | Скопировать имя команды |
| Ссылки | Переход в документацию |

Подробные таблицы аргументов — в разделе [Команды](../commands/general.md).
