# Member profile (website)

Path: `/guilds/:guildId/profiles/:userId`

Discord sign-in required. You can edit your own profile; others’ profiles are view-only (respecting privacy).

## Customization

| Field | Description |
| --- | --- |
| Profile description | Bio (line breaks supported) |
| Banner | Banner URL |
| Thumbnail | Bot profile avatar URL |
| Birthday | Date |
| VK / TikTok / Instagram / Steam | Social links |
| Gender | Male / Female |

**Save** / **Reset** buttons.

## Privacy

“Hide…” toggles:

- join date
- achievements
- gender
- trophies
- profile
- last online
- social networks
- roles
- info (bio)
- banner
- thumbnail
- birthday
- birth year

## Mentions

| Toggle | Description |
| --- | --- |
| New level mention | Ping on level up |
| New achievement mention | Ping on achievement |
| Item find mention | Ping on find |
| Income role recharge mention | Ping when `/role-income` is ready |
| Invited join / leave mention | Invite join/leave |

## Inventory

Search by name or ID. For openable items (cases) — **Open** button with result card (shareable).

Discord equivalent: commands from [Profile commands](../commands/profile.md) and [inventory](../commands/inventory.md).
