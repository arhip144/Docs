# Профиль участника (сайт)

Путь: `/guilds/:guildId/profiles/:userId`

Нужен вход через Discord. Свой профиль можно редактировать; чужой — просматривать (с учётом приватности).

## Кастомизация

| Поле | Описание |
| --- | --- |
| Описание профиля | Био (переносы строк поддерживаются) |
| Баннер | URL баннера |
| Миниатюра | URL аватарки профиля бота |
| Дата рождения | Дата |
| VK / TikTok / Instagram / Steam | Ссылки соцсетей |
| Гендер | Парень / Девушка |

Кнопки **Сохранить** / **Сбросить**.

## Приватность

Переключатели «Скрыть…»:

- дату вступления
- достижения
- гендер
- трофеи
- профиль
- последний онлайн
- социальные сети
- роли
- информацию (био)
- баннер
- миниатюру
- дату рождения
- год рождения

## Упоминания

| Переключатель | Описание |
| --- | --- |
| Упоминание о новом уровне | Пинг при уровне |
| Упоминание о новом достижении | Пинг при достижении |
| Упоминание о найденном предмете | Пинг при находке |
| Упоминание о перезарядке доходной роли | Пинг готовности `/role-income` |
| Упоминание о присоединении / выходе приглашённого | Инвайт join/leave |

## Инвентарь

Поиск по названию или ID. Для открываемых предметов (кейсов) — кнопка **Открыть** с карточкой результата (можно поделиться).

Discord-аналог: команды из [Команды профиля](../commands/profile.md) и [инвентаря](../commands/inventory.md).
