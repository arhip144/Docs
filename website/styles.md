# Стили червоточин (сайт)

Путь: `/dashboard/:guildId/styles` → `/styles/:styleId`

{% hint style="info" %}
Лимит: **5** без премиума, **25** с премиумом.
{% endhint %}

## Основные поля

| Поле | Описание |
| --- | --- |
| Название | Имя стиля |

## Вкладки «Появление» и «Сбор»

Одинаковый набор полей эмбеда для момента появления и момента сбора:

| Поле | Описание |
| --- | --- |
| Описание | Текст эмбеда |
| Заголовок | Title |
| Автор / Иконка автора | Author |
| Футер / Иконка футера | Footer |
| Превью | Thumbnail URL |
| Изображение | Image URL |
| Цвет | HEX; опция «использовать цвет предмета» |
| Кнопка | Текст кнопки |
| Стиль кнопки | Primary / Secondary / Success / Danger |
| Эмодзи кнопки | Эмодзи |

### Плейсхолдеры

Появление: `{item_emoji}`, `{item_name}`, `{item_image}`, `{item_color}`, `{member_name}`, `{member_avatar}`.

Сбор: те же + `{member_color}`, `{amount}`.

Полный список: [Переменные: стили](../variables/styles.md).
