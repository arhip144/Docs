# Работа (сайт)

Путь: `/dashboard/:guildId/jobs` → `/jobs/:jobId`

Команда игрока `/work` доступна с [премиумом](../premium.md). Переменные сообщений: [Переменные: работа](../variables/jobs.md).

## Основные поля

| Поле | Описание |
| --- | --- |
| Название работы | 2–30 символов |
| Эмодзи | Эмодзи |
| Включён | Работа доступна |
| Скрыта | Не видна в списке |
| Описание | До 200 символов |

## Вкладки «Действие 1» и «Действие 2»

У каждого действия:

| Поле | Описание |
| --- | --- |
| Название действия | До 20 символов |
| Право на действие | Объект [прав](permissions.md) |

### Подвикладки Успех / Провал

| Поле | Описание |
| --- | --- |
| Шанс успеха | % (на успехе) |
| Скрыть шанс | Не показывать игроку |
| Сообщения | До 10 текстов (до 200 символов) |
| Изображения | До 10 URL |
| Кулдаун действия (сек) | До 604800 (7 дней); по умолчанию 43200 |
| Кулдаун всех работ (сек) | Общий кулдаун |
| Скрыть кулдауны / награды | Переключатели |
| Награды | До 10: валюта / XP / RP / предмет, мин–макс |

Discord: [Создание работы](../guide/jobs.md).
