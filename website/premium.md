# Premium on the site

Path: `/dashboard/:guildId/premium`

Full feature list and slot limits: [Premium](../premium.md).

## Status

Shows term: **PERMANENT**, end date, or “no premium”.

## Plans

| Plan | Description |
| --- | --- |
| Trial premium (7 days) | Trial period |
| Monthly premium | 🍪100 / 200₽ |
| Lifetime premium | 🍪500 / 1000₽ (recommended) |
