# Market (website)

Path: `/guilds/:guildId/market`

{% hint style="warning" %}
Market requires server [premium](../premium.md). The item must be “Sellable on market”.
{% endhint %}

## Filters

| Filter | Description |
| --- | --- |
| Item | By listing item |
| Role | By role |
| Seller | By seller |
| My listings | Yours only |

## Actions

| Action | Description |
| --- | --- |
| Create listing | Type: Item / Role; quantity; price per 1 |
| Buy | Purchase listing |
| Remove | Remove your listing |

Channel and listing lifetime — [Settings → Market](settings/shop-market.md).

Discord: `/market` and [guide](../guide/market.md).
