# Crash (website)

Path: `/guilds/:guildId/crash`

Real-time game: multiplier grows; cash out before the crash.

## Controls

| Element | Description |
| --- | --- |
| Inventory | Pick item to bet; favorites and search |
| Bet type | Currency / item (cookies — on a special server) |
| Amount | Bet size |
| Auto cash-out | Target multiplier + presets |
| Place bet | Current or next round |
| Cash out Xx | Cash out at current multiplier |
| Chat | Player messages |
| Fairness | Seeds to verify round |
| History | Past rounds |
| Card | Share result |

## Limits

- Items flagged “not crash bettable” cannot be bet.
- Currency may be blocked by “Disable in crash”.
- Discord equivalent: `/crash`.
