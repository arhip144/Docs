# Подарки (сайт)

Путь: `/dashboard/:guildId/gifts` → `/gifts/:giftId`

{% hint style="warning" %}
Создание и редактирование подарков требуют [премиум](../premium.md).
{% endhint %}

## Поля

| Поле | Описание |
| --- | --- |
| Название подарка | Обязательное |
| Эмодзи | Эмодзи |
| Включён | Доступен для получения |
| Цвет | Цвет эмбеда |
| Предметы | Награды: XP / RP / валюта / предметы |
| Макс. уникальных пользователей | Сколько разных людей могут получить |
| Кол-во получений подарка | Лимит получений |
| Кулдаун (в секундах) | Пауза между получениями |
| Дата начала / окончания | Окно доступности |
| Комментарий | Текст |
| Изображение / Миниатюра | URL |
| Право | Объект [прав](permissions.md) |
| Получатели | Список пользователей (если ограничен) |
| ID кнопки | Для кнопки в [конструкторе](message-builder.md) / Discord components |

Discord: [Подарки](../guide/gifts.md).
