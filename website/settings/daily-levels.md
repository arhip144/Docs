# Daily rewards and level roles

## Daily rewards

| Field | Description |
| --- | --- |
| Max. weekly bonus | 0–5000 |
| Day 1–7 | Reward list for each day |

Each day’s reward:

| Field | Description |
| --- | --- |
| Item / currency / XP / RP | What is granted |
| From / To | Quantity range |

Items can also have their own daily drops — “Obtaining methods” on the [item](../items.md).

## Level roles

Up to 80 rules. Each has:

| Field | Description |
| --- | --- |
| Role | Discord role |
| From level | Lower bound |
| To level | Upper bound (optional) |
