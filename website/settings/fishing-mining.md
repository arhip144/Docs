# Fishing and mining

Item drops for fishing/mining are configured on each [item](../items.md) (“Obtaining methods” tab) and in [Administration](../moderation.md) → Activities.

## Fishing

| Field | Description |
| --- | --- |
| Fishing name | Up to 20 characters (shown in command UI) |
| Fishing icon | Emoji/icon |
| Bait | Currency or item consumed per `/fishing` |
| Bait price | Cost per attempt |

{% hint style="info" %}
Without premium, `/fishing` cooldown is 30 sec; with premium — 0 sec.
{% endhint %}

## Mining

| Field | Description |
| --- | --- |
| Mining name | Up to 20 characters |
| Mining icon | Emoji/icon |
| Mining tool | Currency or item per `/mining` |
| Mining price | Cost per attempt |

`/mining` cooldown is the same as fishing (premium removes cooldown).
