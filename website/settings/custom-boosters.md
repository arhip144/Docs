# Custom roles, boosters, CS2, top reports

## Custom roles

Requires [premium](../../premium.md) for `/custom-role`.

| Field | Description |
| --- | --- |
| Custom role permission | [Permission](../permissions.md) object |
| Custom role moderation channel | Where requests are sent |
| Custom role position | Anchor Discord role |
| Display separately | Hoist roles |
| Timed custom roles | Allow timed roles |
| Minimum minutes | Minimum duration |
| Creation limit | How many roles a member can create |

Discord: [Creating a custom role](../../guide/custom-role.md).

## Boosters

| Field | Description |
| --- | --- |
| Stack boosters | Global boosters stack with item boosters |
| Global XP booster | Multiplier % + end date |
| Global currency booster | Multiplier % + end date |
| Global reputation booster | Multiplier % + end date |
| Global luck booster | Multiplier % (can be negative) + end date |
