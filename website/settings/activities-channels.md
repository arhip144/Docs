# Activities and channels

## Activities

Rewards for member actions and level factor.

### For messages

| Field | Description |
| --- | --- |
| XP per message | XP |
| Currency per message | CUR |
| Reputation per message | RP |

### For voice activity

| Field | Description |
| --- | --- |
| XP / currency / reputation for voice | Granted for time in voice |

### For invites / bump / like

| Field | Description |
| --- | --- |
| XP / currency / reputation for invite | For successful invite |
| XP / currency / reputation for bump | For bump (premium rewards) |
| XP / currency / reputation for like | For profile like |

### For first item find

| Field | Description |
| --- | --- |
| XP for first find | XP |
| Currency for first find | CUR |

### Level

| Field | Description |
| --- | --- |
| Level factor | 10–5000; affects level curve |

See also [Obtaining currency, experience, reputation](../../guide/receiving.md).

## Channels

| Field | Description |
| --- | --- |
| Bot notification channel | Bot system messages |
| General chat | Main text channel |
| Level-up notification channel | Level ups |
| Item find notification channel | Item finds |
| Achievement notification channel | New achievements |
| Memes channel | Memes |
| Giveaway publish channel | User giveaways |
| Giveaway moderation channel | Giveaway requests |
| Market channel | Market listings |
| Auction channel | Auctions |
| Custom role moderation channel | Custom role requests |
| Voice creation channel | Join-to-create |
| Member count channel | Voice counter channel |
| Muted channels | Multi-select: no activity rewards in these |
