# Активности и каналы

## Активности

Награды за действия участников и фактор уровня.

### За сообщения

| Поле | Описание |
| --- | --- |
| Опыт за сообщение | XP |
| Валюта за сообщение | CUR |
| Репутация за сообщение | RP |

### За голосовую активность

| Поле | Описание |
| --- | --- |
| Опыт / валюта / репутация за голос | Начисление за время в войсе |

### За приглашения / бамп / лайк

| Поле | Описание |
| --- | --- |
| Опыт / валюта / репутация за приглашение | За успешный инвайт |
| Опыт / валюта / репутация за бамп | За бамп (премиум-награды) |
| Опыт / валюта / репутация за лайк | За лайк профиля |

### За первую находку предмета

| Поле | Описание |
| --- | --- |
| Опыт за первую находку | XP |
| Валюта за первую находку | CUR |

### Уровень

| Поле | Описание |
| --- | --- |
| Фактор уровня | 10–5000; влияет на кривую уровней |

См. также [Получение валюты и опыта](../../guide/receiving.md).
