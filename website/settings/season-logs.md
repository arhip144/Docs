# Сезон, логи, стартовый набор

## Сезон

| Поле | Описание |
| --- | --- |
| Сезонные уровни | Включить отдельный сезонный прогресс |
| Сезонный фактор уровня | 10–5000 |
| Дней сезона | 7–365 |

## Логи

| Поле | Описание |
| --- | --- |
| Вебхук логов | URL Discord-вебхука |
| События | Переключатели по типам (кнопки «Вкл. всё» / «Выкл. всё») |

Бесплатно без премиума:

- Создание команды
- Аудит экономики

Остальные события (каналы, участники, баны, сообщения, эмодзи, вебхуки и др.) — с [премиумом](../../premium.md).

Полный список событий в UI: создание/удаление/изменение канала и сервера; вход/выход/кик/бан участника; роли; реакции; приглашения; стикеры; сообщения; голос; эмодзи; боты; права команд; события сервера; интеграции; вебхуки.

## Стартовый набор

| --- | --- |
| Включён | Выдавать набор новым участникам |
| Список предметов | До 8 записей: предмет/валюта/XP/RP + количество |
