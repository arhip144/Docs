# Season, logs, starter kit

## Season

| Field | Description |
| --- | --- |
| Seasonal levels | Enable separate seasonal progress |
| Seasonal level factor | 10–5000 |
| Season days | 7–365 |

## Logs

| Field | Description |
| --- | --- |
| Logs webhook | Discord webhook URL |
| Events | Toggles by type (“Enable all” / “Disable all” buttons) |

Free without premium:

- Command creation
- Economy audit

Other events (channels, members, bans, messages, emoji, webhooks, etc.) — with [premium](../../premium.md).

Full event list in UI: channel/server create/delete/update; member join/leave/kick/ban; roles; reactions; invites; stickers; messages; voice; emoji; bots; command permissions; server events; integrations; webhooks.

## Starter kit

| Field | Description |
| --- | --- |
| Enabled | Grant kit to new members |
| Item list | Up to 8 entries: item/currency/XP/RP + quantity |
