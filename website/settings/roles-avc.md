# Роли и автовойс

## Роли

| Поле | Описание |
| --- | --- |
| Уведомление о червоточинах | Роль для пинга при спавне |
| Уведомление о бампе | Роль для пинга бампа |
| Уведомление о розыгрышах | Роль для пинга раздач |
| Позиция кастомных ролей | Опорная роль для позиции кастомных |
| Заглушённые роли | Роли без начисления активности |
| Роли новым участникам | До 10 ролей при входе |

## Автовойс

| Поле | Описание |
| --- | --- |
| Канал создания голосовых | Голосовой канал join-to-create |
| Категория автовойса | Куда создавать временные каналы |
| Название автовойса | Шаблон имени (до 100 символов); переменные — в [Переменные AVC](../../variables/avc.md) |

Discord: [Автоголосовые каналы](../../guide/avc.md).
