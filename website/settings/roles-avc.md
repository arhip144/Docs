# Roles and autovoice

## Roles

| Field | Description |
| --- | --- |
| Wormhole notification | Role to ping on spawn |
| Bump notification | Role to ping on bump |
| Giveaway notification | Role to ping on giveaways |
| Custom role position | Anchor role for custom role position |
| Muted roles | Roles with no activity rewards |
| Roles for new members | Up to 10 roles on join |

## Autovoice

| Field | Description |
| --- | --- |
| Voice creation channel | Join-to-create voice channel |
| Autovoice category | Where to create temporary channels |
| Autovoice name | Name template (up to 100 characters); variables in [Variables: autovoice channels](../../variables/avc.md) |

Discord: [Autovoice channels](../../guide/avc.md).
